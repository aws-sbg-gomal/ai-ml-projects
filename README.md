# AI & Machine Learning Projects

**AWS SBG Gomal University** | Engineering Track: AI & Machine Learning

This repository contains all AI and Machine Learning projects submitted by members of the AWS SBG Gomal University engineering collective. Projects cover ML pipelines, LLM-powered applications, AWS AI/ML services (Bedrock, SageMaker), and applied research.

---

## Adding Your Project to This Index

When your project folder is ready and your pull request has been merged, add a row to the index table below following this format:

| Project | Description | Author | Status |
|---|---|---|---|
| `project-folder-name` | One sentence describing what the project does | [@github-username](https://github.com/username) | Active / Archived / In Progress |

Keep the table sorted alphabetically by project name. Do not add your project to the index before your PR is merged.

---

## How to Contribute a Project

1. Copy the `_templates/` folder from the root of this repository into `projects/`.
2. Rename the copied folder to your project name using lowercase letters and hyphens (e.g., `resume-screening-bot`).
3. Fill in the `README.md` inside your project folder before submitting a pull request.
4. Follow the full contribution workflow defined in the [organization CONTRIBUTING.md](https://github.com/aws-gomal-university/.github/blob/main/CONTRIBUTING.md).

## Track Standards

All projects in this repository must adhere to the following:

- A complete `README.md` is required before any PR will be reviewed
- No secrets, credentials, API keys, or `.env` files committed at any point
- Datasets must not be committed to the repository. Use Amazon S3 or provide a download script
- Model weights and large binary files must not be committed. Reference external storage or model registries
- AWS AI/ML service usage must account for cost implications and include cleanup instructions
- IAM permissions must follow the principle of least privilege
